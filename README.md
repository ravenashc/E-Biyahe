E-Biyahe addresses the gap between a modern vehicle and a responsive service. It is an on-demand automated guided electric jeepney. An ESP32-S3 controller makes it follow a guide line around the diorama, identify stations through RFID tags, detect obstacles, and monitor its own battery. Rather than stopping at every station, it stops only where a commuter has requested a ride, where a rider has chosen to get off, or when a passenger presses “Para.” It returns to the depot when idle or when the battery runs low. This reduces unnecessary stops, saving both time and battery energy. Safety rules such as obstacle stopping and emergency stop run inside the vehicle itself, so it keeps operating safely even if the Wi-Fi link to the application is lost. 

The E-Biyahe Python Tkinter application serves as the commuter and operator interface. Commuters can view the route, stations, and schedule on a live map; see the jeepney’s status, estimated location, and ETA; check the fare and travel time for a trip; request a ride between two stations; press “Para”; and cancel a ride before pickup. Operators can monitor the jeepney’s state and battery level, dispatch it, call it back to the depot, trigger an emergency stop, switch between on-demand and patrol service, and review a timestamped event log that is also saved to a file. A built-in demo mode with a simulated jeepney lets every feature be tested without the hardware. By turning raw sensor readings into clear on-screen information and a record of system events, the application shows how a simple software interface can make urban transit more responsive and easier to supervise.
